# Grass Roots Gardening — demo build

A Tech Tradie Media portfolio example. One static page, no framework, no build
step, no dependencies, no third-party requests.

**This is a demo.** The business is retired. The name, phone number and email on
the page are placeholders — the number is in Ofcom's reserved drama range and can
never belong to a real subscriber.

Built as Pilot 1 of the TTM delivery process: intake from a real flyer, scope,
build, verify, before/after capture, handover. Delivery record and proof captures
are held privately.

Live: https://comiccoder23.github.io/grass-roots-demo/
