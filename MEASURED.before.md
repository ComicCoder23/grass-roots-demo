# Before-state measurement note — Grass Roots Gardening

## Scope

`before/index.html` is a **fictional, illustrative legacy-style page** created for the TTM portfolio comparison. It is intentionally not a claim that this was a real client site or that any measured visitor result occurred.

## What the comparison can support

- A visual demonstration of mobile-unfriendly fixed-width layout versus the responsive live demo.
- A feature comparison: plain-text contact details and prices-on-request versus one-tap contact routes and visible from-prices.
- A documented design-review method for a future real client engagement.

## What it cannot support

- Historic performance, traffic, conversion, revenue, or ranking claims.
- A claim that Grass Roots previously had this site.
- A reused benchmark for another client without re-measuring that client's real site.

## After-state evidence

The existing `MEASURED.md` is unchanged and remains the source for the live demo's verified 390×844 observations. Re-run browser measurements for any future deployment rather than copying those figures into a client case study.
